# Loot Integrations

[![CurseForge Downloads](https://cf.way2muchnoise.eu/full_580689_downloads.svg)][curseforge] [![Minecraft Versions](https://cf.way2muchnoise.eu/versions/580689.svg)][curseforge] [![Download on CurseForge](https://img.shields.io/badge/Download-CurseForge-F16436?logo=curseforge&logoColor=white)][curseforge]

Loot Integrations is a lightweight minecraft mod which allows loottables to integrate loot into other loottables through datapacks.
The datapack also lets you control how many items the resulting loottable produces, e.g. limiting the items in a loot chest to 12 items total.

## Installation

1. Install the required mod loader.
2. Download the mod from the official CurseForge page.
3. Place the `.jar` file in your `mods` folder.

> This mod is officially distributed only through CurseForge. Downloads from other websites may be outdated, modified, or unsafe.
